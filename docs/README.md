# Basic Storage Mod - Feature Documentation

This directory contains detailed documentation for the advanced features of the Basic Storage mod.

## Available Features

### [Item Consolidation](item-consolidation.md)
Automatically organize items across all crates connected to a crate station. Consolidates items of the same type into the crate with the largest amount.

**Quick Start**: Sneak + Empty Hand + Right-click on Crate Station

### [Crate Locking](crate-locking.md)
Protect crates from being completely emptied. Locked crates will always retain at least one item, preventing accidental complete extraction.

**Quick Start**: Sneak + Empty Hand + Right-click on Back of Crate

### [Manual Crate Transfer](manual-crate-transfer.md)
Directly transfer items between crates by holding one crate and clicking on another. Quick item movement without using a crate station.

**Quick Start**: Hold Crate + Right-click on Another Crate

### [Shift-Click Placement](shift-click-placement.md)
Place crates as blocks near crate stations without them being inserted into the station network. Makes building storage systems easier.

**Quick Start**: Shift + Right-click with Crate Item

## Feature Overview

| Feature | Trigger | Use Case |
|---------|---------|----------|
| **Item Consolidation** | Sneak + Empty Hand on Station | Organize items across multiple crates |
| **Crate Locking** | Sneak + Empty Hand on Crate Back | Protect valuable items from complete extraction |
| **Manual Transfer** | Hold Crate + Click Crate | Quick item movement between crates |
| **Shift-Click Placement** | Shift + Crate Item | Place crates near stations easily |
